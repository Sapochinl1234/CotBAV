# Política de Privacidad

CotBAV recopila datos mínimos necesarios para operar la experiencia de cotización y la autenticación con Google.

## Datos tratados

- Nombre y correo electrónico de Google para acceso a la cuenta
- Preferencias de cotización y configuración personal
- Datos de uso para mejorar el servicio

## Finalidad

- Autenticar el acceso del usuario
- Guardar su historial de cotizaciones
- Mejorar la experiencia y la seguridad

## Derechos del usuario

El usuario puede solicitar acceso, actualización o eliminación de sus datos mediante correo electrónico a privacidad@cotbav.example.
